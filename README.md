# Сцена PersonScene

## Персонаж

В данной сцене реализованы базовые механики управления персонажем, а именно ходьба, бег и управление камерой.
Также реализованы дополнительные механики: прыжок, крауч и зум (выключены).

Параметры механик можно изменять в компонентах объекта `First Person Controller` и `First Person Camera`.

Помимио этого, для многих действий есть аудиокомпоненты, сейчас ублюдские, но потом можно на нормальные поменять.
