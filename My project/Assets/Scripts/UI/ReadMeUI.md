# UI система 
## Сделал: Платон
все переходы между вкладками ведутся через **SetActive** объекта содержащего в себе элементы конкретной панели UI
### Main menu
Главное меню состоит из 3-ёх кнопок и названия, 

Кнопка **start** выключает главное меню(всё)

Кнопка **settings** выключает главное меню и включает меню настроек

Кнопка **exit** закрывает приложение через Application.Quit() что не может быть продемонстрированно в юнити и будет работать только в билде

### Pause menu
Вызывается на кнопку **escape**, закрывается также. 
Останавливает внутриигровое время
